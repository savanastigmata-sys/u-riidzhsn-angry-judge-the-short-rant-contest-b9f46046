Write a short, funny rant about an everyday annoyance and let a furious judge decide which one lands hardest. This entry rants at a self-checkout machine over a single avocado: a deterministic Python program that validates the rant against the 400-character gate and writes it to `entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 -P -s main.py
```
